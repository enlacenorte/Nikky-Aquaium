## 🌊 Overview

**Taylor'd Aquatics** is a living, boutique interactive web aquarium application crafted in a vibrant 3D Pixar casual-game aesthetic (*Fishdom / Abyssrium*). Designed as an engaging, memorable gift and conversion landing experience for **Taylor'd Aquatics**' bespoke aquatic maintenance services in Brighton & Hove.

### ✨ Key Features
- **Decoupled Kinematic Scuba Diver**: A 3D Pixar-style scuba diver floats organically in 60 FPS buoyancy kinematics with an authentic wooden chalkboard displaying rotating client reviews and core services.
- **Dynamic Exhaust Regulator Bubbles**: Bubble streams spawn in real time tracking the diver's helmet.
- **Canvas Living Fish Boids**: Monotonic spinal kinematics simulating Clownfish, Blue Tang (Dory), and Yellow Tang with curiosity and touch evasion behaviors.
- **High-Contrast 3D Pebble Branding**: Handcrafted river pebble typography nestled into the seabed gravel.
- **Tactile River Stones**: WhatsApp, Telephone, and Facebook contact portals on illuminated mossy rocks.
- **Silent Sunken Treasure Chest**: Tap to release natural micro-bubble flurries with zero intrusive noise.
- **Responsive Dual-Viewport Stage**: Pixel-perfect adaptation across Desktop (16:9) and Mobile Smartphones (9:16).
- **In-App Exit Button [X]**: Seamless navigation control with direct contact options.

## 🛠️ Tech Architecture
- **Rendering**: Multi-layer 2.5D DOM + Canvas 2D 60 FPS kinematic spine solvers.
- **Audio DSP**: Pure Web Audio API synthesized cavitation, sub-bass resonant filters, and water clicks (no heavy media files).
- **Zero Framework Bloat**: Pure vanilla modern standards for ultra-fast mobile loading (<1s).
